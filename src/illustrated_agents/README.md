# `TinyAgent`

The source code for "An Illustrated Guide to AI Agents" where you build an `TinyAgent` from scratch by building it up with one module at a time:

![../../images/tinyagents.png](../../images/tinyagents.png)

* LLM (`src/illustrated_agents/llm.py`)
* Memory (`src/illustrated_agents/memory.py`)
* Tools (`src/illustrated_agents/tools.py`)
* MCP (`src/illustrated_agents/tools.py`)
* ReACT (`src/illustrated_agents/planning.py`)
* Reflection (`src/illustrated_agents/reflection.py`)
* Skills (`src/illustrated_agents/skills.py`)
* Multi-Agents (`src/illustrated_agents/tools.py`)
